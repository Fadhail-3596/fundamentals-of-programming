# Fundamental Pemrograman

Repositori ini berisi panduan praktis untuk mengembangkan keterampilan dasar yang dibutuhkan dalam mempelajari dan memahami pemrograman.

## Materi

- Membaca Dokumentasi Resmi
- Memahami Error dan Melakukan Debugging
- Membaca dan Memahami Kode
- Menyusun Catatan Teknis yang Dapat Digunakan Kembali

## Referensi

- [Dokumentasi Python](https://docs.python.org/3/)
- [MDN Web Docs](https://developer.mozilla.org/)

## Tujuan

Mendokumentasikan pendekatan praktis untuk mempelajari pemrograman, menyelesaikan masalah, memahami kode yang belum dikenal, dan membangun kebiasaan belajar teknis yang efektif.
